# Phase 8 — Bonus

Chaque utilisateur reçoit un bonus de bienvenue de 1 500 FCFA dès la création du compte. Le compte ne peut cependant pas se connecter, investir ou retirer avant vérification de son e-mail. Le crédit est une écriture financière atomique, unique par utilisateur et placée dans `bonus_balance`.

Le bonus n’est pas retirable. Lors d’un investissement, le solde bonus est consommé avant le solde disponible. Les codes bonus sont contrôlés côté serveur ; leur création sera réservée à l’administration.
