# Phase 3 — Espace client

Livré : interface client responsive PX MINERALS, tableau de bord, carte virtuelle interne, synthèse des soldes séparés, activité récente, aperçu des investissements, parrainage, profil lecture seule et écran de sécurité lecture seule.

Toutes les données sont chargées après contrôle de session par l’API. La carte est strictement virtuelle : elle ne représente pas une carte bancaire.

Les écrans Dépôt, Retrait, Investissements, Historique, Bonus, Documents et Support sont volontairement présentés comme indisponibles dans cette phase ; ils seront activés uniquement lorsque leurs règles serveur seront développées.
